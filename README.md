# MC Inventory

This repository contains an application built using **Flutter** and **Dart**. The goal of this project is to replicate and modernize the current McDonald’s inventory workflow. Many franchises still rely heavily on paper-based processes, so this project aims to transition those workflows into a responsive **web** and **mobile** application.

---

## Problem

McDonald’s locations commonly use pen-and-paper methods to record inventory, which are later manually entered into a PC that communicates with McDonald’s servers. This workflow is outdated, inefficient, and prone to human error.

---

## Solution

This project introduces a web and mobile-friendly application hosted locally at a McDonald’s restaurant. The system communicates directly with McDonald’s API services to update and manage store inventory in real time.

---

## 📌 Disclosure

This project is an **example** demonstrating how an application *using McDonald’s APIs* **might** look and function. It is not an official McDonald’s tool and does not communicate to McDonald’s in any way.

---

## ✨ Features

The application is intentionally designed to be simple, efficient, and aligned with McDonald’s operational workflow.

- Truck Order Management  
- Basic Count Sheet Interface  
- Item Storage System  
- Clean and intuitive UI

## 🚀 Usage

Due to PocketBase limitations, a single-click installer is not available. However, setup is straightforward:

1. Navigate to the PocketBase directory (e.g., `../pocketbase_0.31.0_windows_amd64`).
2. In a terminal, run: `pocketbase serve`
3. Once PocketBase is running, launch the main Flutter application.
4. Log in using the default credentials.
5. Explore and test the system.
